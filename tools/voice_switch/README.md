# 主机本地语音切换

本工具在主机运行；辅机 Xen 提供当前地图和已保存身法目录，并通过现有 KMBOX 按住说话热键通知收音。音频只在主机内存中识别，不上传、不保存。不执行身法动作；辅机成功载入并更新下一次热键模板后才播放成功音。

## 安装与启动

Windows x64、Python 3.12（本轮验证版本）及默认麦克风/输出设备。第一次安装需要联网下载固定依赖及约 32.7 MB 官方模型包；模型安装只保留约 5 MB 的三份 int8 权重、tokens 和模型说明。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -HostAddress <辅机地址>
```

也可直接运行 `.venv\Scripts\python.exe -X utf8 -B client.py --host <辅机地址>`。默认 TCP 端口 5014；`--port` 用于对齐辅机设置，`--model` 只用于指定已核验模型位置。工具保持后台工作，可最小化终端；按 Ctrl+C 明确退出，不注册服务或开机自启。安装脚本创建同目录 `.venv`、下载并核对固定模型 SHA-256，模型存入 `model`。不要与安装同时运行客户端。

安装包 SHA-256：`b2f7c89690dc8ce4c6ed6afeab7cd800c36ad1421fb6b6302b4a4b194cf7f35f`。模型来源及许可证见 [LICENSES.md](LICENSES.md)。`prepare_model.py --archive <已下载压缩包>` 支持复用相同官方包，仍校验摘要。

## 使用约束

先在辅机启用既有身法测试并保存语音热键；每个候选方案保存实际地图标识和一个简短中文口令。建议使用差异明显的完整中文名称，如“跳箱”“上桥”；数字写成中文，不使用拉丁缩写或标点。模型不支持的口令及同音歧义会被排除并记本地终端日志，其他候选继续可用。未保存编辑不覆盖，真实动作仍由原执行热键触发。

按住语音键说话，松开后等待短提示音：高音表示辅机确认新方案已提交；低音表示未确认成功。低音可能是没识别、歧义、拒绝、断线或超时；超时不证明辅机没有切换。每轮只响一次，多个不同关键词拒绝，不按第一个词任选。模型就绪及目录同步前不会补启动旧按住轮次。

断线取消当前轮次，三秒后恢复连接，只同步新目录，不自动重试选择。单次收音上限 10 秒，等待回执上限 8 秒，辅机完整轮次上限 20 秒；目录变化或取消立即结束本轮。麦克风仅在有效按下期间打开，松键关闭，退出释放。两种固定短音使用系统默认输出设备，可能被录屏的系统声音轨道录入。日志记录轮次和原因，保存在工具目录 `logs/voice.log`，单文件最多 2 MiB、保留两份轮转，不保留原始音频。

## 协议和验证

UTF-8 JSON 行、每行最多 64 KiB、单 TCP 连接。辅机发送 `catalog/begin/end/cancel/result`，主机发送 `ready/select/fail`。轮次、地图 epoch 和候选 revision 必须匹配，结果同时对应实际 plan_id。文件身份只用作目录键，客户端不接收或提交方案路径。

专项：仓库根运行 `py -3 -X utf8 -B tests/voice_switch_client_tests.py`。协议回归与官方音频推理只能证明软件契约及离线模型可用，不能代表用户口令准确率、麦克风首音、双机延迟或真实游戏效果。

使用已安装依赖的 Python，加 `--model <最小模型目录> --samples <官方模型包/test_wavs>` 运行同一测试可执行真实模型回归；两参数必须一起提供。该测试不打开麦克风。
