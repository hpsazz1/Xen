## 获取与升级

GitHub Release 提供带 MIT 许可的源码快照与公开说明。模型权重、第三方运行库和个人设备配置按各自授权准备，参见[构建与开发](../development.md)。

已配置的双机交付环境继续使用原包根目录 `Start-Xen.cmd`。本次正式采用保留已验证路径，即使目录名含 `rc1` 也不通过改名迁移用户数据；正式采用记录与包内发布说明标明状态。标准多后端包仍通过根目录 `XenLauncher.exe` 选择 Worker。

升级保留本机配置、模型、弹道档案、采集数据和验收记录。辅机仅用于采集，训练在主机执行；不要跨机复制训练环境绑定。清理只处理确认不再使用的生成产物，不清空整个 `cache/`。
