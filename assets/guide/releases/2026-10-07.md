# Xen 2026.10.07

GitHub Release 仅上传单文件教程，更新说明及验证结果列在发布页面。模型、默认配置与全部运行库保留在本地完整便携包中，不作为 Release 附件上传；下面的包内容和启动步骤指本地完整包。GitHub 自动生成的源码压缩包不是可直接运行的安装包。

完整解压后双击根目录 `Start-Xen.cmd` 或 `XenLauncher.exe`；双击 `Xen-guide.html` 阅读教程。不要只复制一个 EXE，也不要在压缩包内直接运行。

## 包含内容

- 同一源码构建的 NVIDIA、DirectML、OpenVINO 三套独立运行库，界面支持 CPU、CUDA、TensorRT、DirectML、OpenVINO 切换；切换时由 Launcher 重启匹配的 Worker。
- ONNX Runtime、CUDA/cuDNN/TensorRT、DirectML、OpenVINO、OpenCV、NDI 和 VC++ 应用本地运行库，以及对应许可资料。
- 现役 `models/14wv11.onnx`、完整 `config.ini` 和含图示/GIF的单文件中文教程。
- 身法、手机道具助手、源端工具、审核/训练脚本及离线复盘工具。手机助手入口为 `tools/lineup/Start-Lineup.ps1`。

## 默认参数与换机使用

默认使用 CPU 推理和本机桌面采集；物理输出关闭。发行参数同时保存在代码默认值中：缺少 `config.ini` 时自动重建，已有配置不会自动覆盖。个人设备地址、凭据、NDI源、真实标定和训练环境绑定需要在新电脑填写。

身法数值采用用户在辅机最后保存的配置：旋转跳90°/200ms；Long Jump每侧25°/170ms、固定A左→D右；Ctrl延迟650ms/按住200ms；动作延迟0ms、结束保护150ms、相对滚轮报告；游戏灵敏度参考1.4、m_yaw参考0.022。默认身法总开关关闭，两种动作与Ctrl子项保留配置，使用前设置对应游戏跳跃绑定和设备。

新包不携带开发机生成的TensorRT引擎缓存；首次选择TensorRT会在当前电脑生成。启动不依赖开发机路径，不逐次哈希整包，不因用户新增日志、模型或修改配置而拒绝启动。中文配置路径可正常读取和原子保存。必要的后端匹配、路径检查和输出保护保留。

## 硬件和可选工具

Windows x64。CUDA/TensorRT仍需兼容的NVIDIA GPU和驱动；DirectML需支持DirectX 12的GPU与驱动；OpenVINO默认CPU，GPU/NPU需要对应硬件及驱动。运行库随包提供不等于安装显卡驱动，无法把任意硬件变成支持所有后端的设备。普通使用可先保留CPU默认。

原生程序与HTML教程不依赖Python。训练、校准资料生成、离线复盘等Python脚本仍需各自的Python环境；训练环境按界面检查和配置，不随包搬运开发机虚拟环境。NDI来自 [NDI官方](https://ndi.video/)。

升级前保留旧包的配置、`models/`、`cache/recoil/`、采集数据和需要的报告。公开附件不分发私人运行归档或来源权利链未确认的社区弹道；已有压枪用户可迁移自己的完整profiles目录，包含active及其current/previous引用。
