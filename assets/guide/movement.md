# 身法：旋转跳与 Long Jump

[返回 README](../../README.md#身法演示) · [完整控制说明](controls.md)

## 本地训练的手动身法编排

在 **调试 → 身法编排** 中可以添加 W/A/S/D、空格、Left Ctrl 和水平鼠标旋转。每行分别设置开始时间与持续时间（毫秒），旋转还可设置左右方向和角度；时间相对本次脚本启动，允许不同按键及按键与旋转并行。同键重叠区间连续持有，连续点按需要留空；重叠旋转会被拒绝。

默认从脚本首次空格起屏蔽物理 W/A/S/D，脚本方向键仍可输出。可以选择屏蔽哪些键、指定开始时间和时长；屏蔽时长为 0 表示直到脚本结束。没有空格且未指定起点时不屏蔽。结束先释放软件按键再解除屏蔽，仍持续按住的物理 W 会恢复前进；不模拟恢复启动时的旧键态。取消、失焦和故障同样进入清理，释放未确认时禁止继续测试。

停止 Runtime 后编辑方案，通过“已保存方案”下拉框选择即可载入和继续修改，无需填写路径。改参数、录制和测试都不自动保存方案。点击“保存方案”更新当前方案；尚未保存过的方案，首次保存时创建文件，以后更新同一个文件。“另存新方案”保留原方案并创建另一份。列表只显示主动保存的方案，不包含测试快照。名称、地图、点位及起始说明随文件保存；目前由用户对齐位置和朝向，不自动识别或导航。每份方案最多 16384 个动作、60 秒，单段旋转不超过 360°。

点击一次“启用身法测试”，之后直接点击“测试一次”或使用已启用并保存的调试测试热键。修改参数、保存和载入均无需重复准备或勾选输出；每次启动冻结最新有效草稿及共享灵敏度，无效草稿不会回退执行旧参数。运行期间改参只影响下一次，忙碌时不排队。测试复用已有 KMBOX NET 连接、源端焦点与急停设置，不需要启动采集检测 Runtime；允许人工持续按住 WASD，按方案接管。关闭测试、急停、源端失焦、输入失效或执行故障会停止执行并撤销测试启用状态，重新打开应用也需重新启用。

原旋转跳和大跳仍在辅助页，原触发与选向方式保持不变。编排页的复制按钮生成**主动发送空格、固定方向**的可编辑副本，不等同于原物理跳跃触发预设。

计时采用统一单调时间轴；系统调度和设备确认可能迟到，完全错过短按区间会明确失败，不能保证 1 ms 游戏动作精度。每次测试保存计划、灵敏度、累计位移、实际总耗时及清理结果，均不代表真实转角或跳跃成功。用于本地练习和教学时，结合录像逐项调整；地图点位自动集成尚未加入。

## 本地语音切换已保存方案

在身法编排页填写地图标识，或点击“使用当前地图”，再填写单一“语音口令”并保存。同地图口令不能重复，跨地图可复用；清空口令仍可保存为手动方案。旧方案读取时口令为空，原动作和手动用法保持兼容。未保存编辑不会发布到语音目录。

辅机设置中绑定并保存“语音按住说话”键（默认空），网络地址与允许来源沿用 GSI 设置，语音 TCP 端口为 5014。桌面 App 持续接收地图，停止 Runtime 不关闭地图接收器。主机安装并启动独立的[语音工具](../../tools/voice_switch/README.md)，只需指定辅机地址，使用系统默认麦克风和播放设备，音频不离开主机。

先按原流程启用身法测试，再按住语音键说口令，松开提交。成功音表示方案和下一次热键模板已经切换，动作仍由原测试热键触发。未确认成功音可能表示未识别、拒绝、断线或超时；超时不能证明辅机未完成切换。每次交互仅一轮，不自动重试。

地图未知或过期时不能按旧地图语音选择；换图撤销语音选中方案的下一次模板，但保留测试启用状态。手动选择及实际编辑可接管草稿，原手动测试不增加地图条件。运行、身法录制、输入训练、有未保存草稿或停止期间拒绝语音切换；OBS 教学录屏不属于输入训练。捕获热键、监听器重建、断线或急停取消本轮，恢复后须先释放再按下。

## 录制完整身法过程

身法编排页点击“开始录制”，可记录 WASD、空格、Left Ctrl、鼠标 XY 和滚轮，以及 Xen 自动发送的身法动作和每个 WASD 键的屏蔽、恢复。录制是被动观察，不要求启用物理输出，也不改变现有 Runtime。要录制原 Long Jump 或旋转跳，先启动并启用原身法 Runtime，再开始录制、完成动作，最后点击“停止录制并生成方案”。停止录制不会停止原身法；回放前需停止 Runtime，防止滚轮再次触发原身法。

原始记录保存在独立调试目录的 `movement-recording.json`，仅包含身法相关输入。软件命令分别保留请求与回执时间，屏蔽逐键保存。仍按着 W 的情况下，记录会同时保留物理 W 持有和 W 的屏蔽区间；生成方案中的“物理轨道”会扣除对应屏蔽区间，软件 A/D 等动作照常执行。结束后仍沿用释放软件键、恢复当前物理直通的行为。

鼠标解释可选择相对位移、累计坐标或仅存原始。相对/累计按所选方式生成候选，完整原始事件始终保留；设备 monitor 的坐标及物理来源尚未实机标定，若固件报告混入软件移动可能重复计数，需短录制核对。生成的鼠标位移按 10 ms 合并为可编辑段，可修改 X/Y counts、水平角度和时长；原始文件不做此合并。滚轮保存发生时刻、方向及档数，按开始时刻发送一次，不偷换为空格跳。按键、逐键屏蔽和鼠标仍可并行。

有效录制替换编辑器中的当前草稿，可继续修改和测试，点击“保存方案”才写入方案库；已经选择的方案仍是保存目标，想保留原方案时点击“另存新方案”。原始录制与测试报告仍作为调试记录保留，不加入方案列表。录制最多60秒；本机队列缺口、超限、无效输入、未知命令回执或停止时身法尚未清理会保留原始记录并拒绝生成完整回放。UDP源端丢包不可完全检测；录制成功不是游戏动作已精确复现的证明。急停/取消结束本次录制并留存原始记录，不自动回放。

## 原有快捷身法

两项功能都在**辅助 → 身法**中，当前需要 KMBOX NET。先打开身法总开关，再选择要使用的动作；旋转跳和 Long Jump 可以分别开关。

新配置的身法总开关默认关闭，两项动作和 Ctrl 子项预先选中。发行参数为旋转跳 90°/200ms、Long Jump 每侧 25°/170ms、Ctrl 延迟650ms并保持200ms、动作后保护150ms，滚轮使用 relative 报告。已有配置保留自己的值；这些是起始参数，不保证所有场景效果相同。

| 功能 | 可以做什么 | 默认触发 |
|---|---|---|
| 旋转跳 | 跳跃时配合方向键转动视角 | 滚轮向上 |
| Long Jump | 跳跃时依次向左、向右转动，可配合一次定时蹲键 | 滚轮向下 |

## 怎么开始

1. 在**设置**中确认 KMBOX NET 已连接，按键和急停设置正确。
2. 在**辅助 → 身法**中启用所需动作，选择触发方式。两项功能使用不同的触发。
3. 在游戏内把对应滚轮方向或按键绑定为跳跃。Xen 配合这次跳跃做动作，不额外补发跳跃。
4. 启动 Runtime 并明确允许本次输出，在合适的练习环境中尝试；按 **End** 可急停。自动调试也须在已授权的有界任务内执行并确认释放结果。

角度决定转动幅度，时长决定动作持续多久。Long Jump 的角度和时长按每一侧设置。先用自己的现有配置，再按实际体验调整；录像里的效果不保证在其他点位复现。

旋转跳由物理 **A / D** 选择左 / 右：可以先按方向再触发，也可触发后选侧；未按或同时按 A/D 时最多等待 1 秒，超时取消。选定后本次方向锁定，松键或反按不改变这一轮方向。Long Jump 固定先 **A 向左 → D 向右**，不需要选择方向。

Long Jump 的蹲键按设定时间触发，并不会判断是否落地。动作期间会暂时屏蔽物理 W/A/D，直到转向、Ctrl 和清理完成；因此结束后仍按住 W 会恢复前进。软件 Ctrl 会在完成、关闭或急停时释放，不释放你物理按住的 Ctrl。

动作忙碌、清理及保护期间的新触发不排队。修改参数从下一轮生效，关闭功能立即取消当前动作；清理后默认保护 150ms，结束后需要新的触发。设备清理未确认会保留故障提示，应停止并检查设备后再启动。上述时间是软件计划，不是落地时刻或游戏效果保证，完整说明见[控制指南](controls.md#旋转跳与long-jump)。

## 烟雾配方人工调试

在**调试 → 身法编排**载入烟雾方案后，可用“复制定位指令”取得说明中的
`setpos x y z;setang pitch yaw roll`。自行粘贴到游戏练习控制台，确认站位和瞄角，
关闭控制台并拿出烟雾弹、松开物理鼠标按钮，再启用身法测试。全局测试键可以绑定为
**F11（122）**；每次按下执行当前方案，修改时间后下一次执行新草稿，End取消并释放输入。

动作列表支持鼠标左/右键：开始时间为按下时刻，时长结束时释放；双键可重叠，
需要先松右键时将其结束时间设得更早。同刻跳跃与释放会先发送空格，再释放鼠标。
这只是设备命令顺序，不能证明游戏实际输入帧或烟雾落点。

使用 `tools/smoke_plans/generate.py` 可从已核对清单生成初稿。初稿参数是人工调试起点，
不是来源提供的实测时序；需要跑动距离、视觉释放参照或第二站位的条目保留在清单，
补齐后再编排。保存覆盖当前方案，“另存新方案”保留对照版本；要从列表精简，先退出执行，
将不用的文件移出正式 `cache/movement/plans` 目录，再刷新方案。
