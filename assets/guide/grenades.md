# 道具清单与参考图对齐

入口为**调试 → 道具测试**，方案在 `cache/grenade/plans`。身法仍使用独立的 `cache/movement/plans`；两页共用原动作执行器。先停止 Runtime，再启用道具测试。软件不自动拿出道具或移动到站位。

手机网页随辅机 Xen 启动，地址显示在启动提示与日志中，默认端口 5015；手机与辅机须网络互通。页面编译在 Worker 内，不需要主机另起 Python、语音工具或网页服务器。地图和本地阵营直接跟随辅机已有 GSI；换图、换边或状态失效时撤销页面旧选择，没有有效状态时显示等待。手机方案选择目前仍是界面预览，尚未接入真实执行。下方桌面清单为既有已实现入口。

参考图采集、方案制作与调试工具继续保留在游戏主机，只在制作道具时使用；调试完成后将方案与站位/瞄点参考资源打包到辅机。首次全屏参考图采集与日常 320×320 ROI 对齐是不同步骤，主机制作工具不承担手机网页服务。

## 使用清单

1. 在辅机的快捷键设置中开启道具助手，应用四向布局并保存。默认使用独立方向区的右、上、下、左；若你的“小键盘”实际是数字区 6/8/2/4，通过已有按键捕获分别绑定，两区不混用。End 保留全局急停。
2. 在主机运行 `tools/voice_switch/start.ps1 -HostAddress <辅机地址>`。默认仅使用清单与双图，无需麦克风或语音模型；可选语音的安装与启动见[主机工具说明](../../tools/voice_switch/README.md)。
3. 点按**右键**打开当前地图道具清单，按 T、CT 和未标注分组。点击方案后收起清单并恢复此前游戏窗口；辅机确认载入后，在角落显示站位图和瞄点图。未明确阵营的方案不会被猜测归类；缺图会显示待采集状态。
4. 自己拿出正确道具，照站位图站好，把视角大致转到瞄点附近，再点按**上键**。软件复用采集链取得 320×320 ROI，进行短时局部对齐。对齐过程中停止手动移动视角。
5. 对齐成功后双图**无声消失**，不会自动投掷。点按**下键**，软件重新检查新画面后执行该方案原动作一次；画面不符时拒绝执行，需要重新对齐。
6. **左键**取消本次道具操作并隐藏图片，保留道具测试的启用状态；**End**撤销全局测试许可并清理输入。打开清单、换方案或换地图都会使旧对齐结果失效。

双图默认右上角，可通过主机启动参数 `-Corner left` 放到左上角。清单可以点击；参考双图不抢焦点并允许鼠标穿透。清单点选和可选语音共用已保存方案，选择本身不执行投掷。语音需另绑非冲突按键并显式以 `-Voice` 启动，不占用默认右键。

## 首次采集与 Mirage 测试

每套按“人工试投成功 → 复位 → 采站位图 → 采瞄点图 → 自动对齐试投”顺序验证。参考图不能由方案坐标凭空生成。既有 Mirage T1～T5 VIP R2 和 T1～T5 B小烟 R1 已有人工成功反馈，仍应在本次采图前复核；其余方案保持待人工确认。

人工试投保留原流程：选方案，点击“复制定位指令”，在练习地图控制台粘贴；关闭控制台，拿出道具并松开鼠标按钮和方向键，启用道具测试后按 **F11**。修改草稿影响下一次 F11，保存或另存才写入方案库。F11 不要求参考图；下键必须先完成图像对齐。

采集工具及完整命令见[双图资源采集](../../tools/voice_switch/README.md)。工具支持导入全屏 PNG，或延时采集主机屏幕；站位图应看清所站位置，瞄点图必须恢复原站位、姿态与准确瞄角。原图保留，320×320 范围和瞄点标记只在提示窗绘制。

资源存入 `cache/grenade/references/<方案文件stem>/`，包括 `reference.json`、`standing.png`、`aim.png`。主机用于显示，辅机用于图像对齐，两端须使用同一套资源。清单绑定原方案内容、人工确认记录、源分辨率、ROI 几何与图片摘要；更改动作、几何或图片后须重新确认资源，不能沿用旧对齐结果。采图尚未完成时仍可清单点选和人工 F11 测试。

## 结果边界

对齐只支持已正确站位、接近参考方向的局部调整。共同纹理不足、场景歧义、站位变化、断流、失焦或输入状态失效时停止，不盲目寻找远处瞄点。使用现有鼠标换算、延迟和步长上限；这些参数和网络时钟须在实际双机环境验证。

自动报告仅证明图像与执行契约，不能证明烟雾落点正确。每套 Mirage 的落点、重复性和输入释放由游戏实际观察验收；构建、合成图、窗口检查分别记录，不合并宣称游戏通过。

方案精简时先停止测试，将不用的文件移至库外备份后刷新。`tools/smoke_plans/generate.py` 只生成库外来源初稿；不为未知动作补写固定时长，不修改已通过方案的动作参数。
