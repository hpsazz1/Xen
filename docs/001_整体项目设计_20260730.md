## 1. 项目定位

Xen 是基于 C++20 原生实现的 Windows AI 辅助瞄准工具。核心管线：**截图采集 → 目标检测推理 → 瞄准控制**。

**运行模式（按隔离强度从高到低排列）：**

| 模式 | 采集端 | 推理端 | 典型场景 |
|---|---|---|---|
| 双机 NDI | 主机 OBS/NDI Screen Capture | NDI SDK | 高画质局域网串流 |
| 双机 UDP | 主机 FFmpeg gdigrab | UDP Recv | 极低延迟自定义 |
| 本机 DXGI | 本机 Desktop Duplication | 本机 ONNX Runtime | 单机零配置 |

## 3. 采集方式全矩阵

采集方式，按隔离强度从高到低：

| # | 方法 | 配置值 | 原理 | 优点 |
|---|---|---|---|---|
| 1 | NDI 网络 | `ndi_capture` | 主机 NDI Screen Capture → 辅机 NDI SDK | 网络隔离、高画质、mDNS 自动发现 |
| 2 | UDP 推流 | `udp_capture` | 主机 FFmpeg gdigrab → UDP MJPEG → 辅机 | 极低延迟、轻量 |
| 3 | Duplication API | `duplication_api` | IDXGIOutputDuplication 桌面 | 零配置、延迟最低 |

## 4. 瞄准控制全链路

调参体系：

```
┌──────────────────────────────────────────────────────────────┐
│                      调参层级（由底向上）                       │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  ① AI 模型层         模型选择、置信度阈值、输入尺寸、NMS       │
│        │                                                      │
│        ▼                                                      │
│  ② 核心移动层        灵敏度(Sens)、FOV、速度倍率、动态FOV      │
│        │                                                      │
│        ▼                                                      │
│  ③ 移动修正层        EMA 平滑、死区、单帧最大移动限制           │
│        │                                                      │
│        ▼                                                      │
│  ④ 轨迹预测层        卡尔曼/AB预测、预测间隔、未来位置数         │
│        │                                                      │
│        ▼                                                      │
│  ⑤ 轨迹曲线层        贝塞尔曲线、步进量化                           │
│                                                               │
└──────────────────────────────────────────────────────────────┘
```

### 4.1 AI 模型层

| 参数 | 说明 | 默认值 |
|---|---|---|
| `model_path` | ONNX 模型路径 | `yolo11n.onnx` |
| `conf_threshold` | 置信度阈值，低于此值丢弃 | `0.25` |
| `nms_threshold` | NMS IoU 阈值 | `0.45` |
| `input_width/height` | 模型输入尺寸（如 320/416/640） | `320` |

### 4.2 核心移动层

这是调参的基石——必须知道游戏内的物理引擎映射（灵敏度、FOV），才能计算鼠标移动量。

| 参数 | 说明 |
|---|---|
| `sens` | 游戏内鼠标灵敏度。 用此值做 counts→像素 换算 |
| `fov_x / fov_y` | 游戏引擎的水平/垂直视角（度）。务必与游戏内同步 |
| `fov_size` | 以准星为中心的锁定半径（像素），超出不锁定 |
| `dynamic_fov` | 锁定后收缩到最小范围，丢目标后张开，减少切锁干扰 |
| `speed_min / speed_max` | 移动速度的下限/上限乘数 |
| `pid_p / pid_i / pid_d` | PID 三参数 |
| `max_move_per_frame` | 单帧最大移动像素（防甩飞） |

### 4.3 移动修正层

| 参数 | 说明 |
|---|---|
| `ema_smoothing` | EMA 平滑系数（0=不平滑，0.85=重平滑） |
| `deadzone` | 死区像素（小于此值不移动，防止静止微抖） |
| `decay_curve` | 减速曲线（接近目标时减速的力度） |

### 4.4 轨迹预测层

待设计。需要先定义观测时间戳、目标状态和丢帧策略，再选择卡尔曼或 Alpha-Beta 等预测器；当前不锁定算法。

### 4.5 轨迹曲线层（拟人化）

待设计。实现前需明确输入输出单位、单帧最大位移和可验证的轨迹指标，避免将随机扰动直接叠加到控制热路径。

## 8. 数据流（观测→控制闭环）

```
                            ┌──────────────────┐
                            │  Game Profile 切换 │←─ 热键触发
                            └──────────────────┘
                                     │
┌─────────┐    ┌──────────┐    ┌─────▼────┐    ┌──────────┐    ┌──────────┐
│ Capture │───→│ Detector │───→│   Aim    │───→│  Mouse   │───→│   游戏   │
│ 3种采集 │Mat │ YOLO ORT │Dets│           │Cmd │       设备  │    │          │
└─────────┘    └──────────┘    │          │    └──────────┘    └──────────┘
     ↑                          │ 核心移动 │                        │
     │                          │ 移动修正 │                        │
     │                          │ 轨迹预测 │                        │
     │                          │ 轨迹曲线 │                        │
     │                          └──────────┘                        │
     └─────────────────── 游戏画面刷新 ──────────────────────────────┘
```

**双机模式扩展：** 主机侧替换 Capture 环节为 OBS/FFmpeg/scrcpy 推流，辅机侧 Capture 变为对应的接收端（NDI/UDP/采集卡），后续 Pipeline 不变。

## 9. 线程模型

```
┌──────────────────────────────────────────────────────────┐
│  主线程 (UI)                                             │
│  ImGui Overlay 渲染 + 热键处理 + 实时调参                  │
├──────────────────────────────────────────────────────────┤
│  采集线程 (CaptureThread)                                 │
│  取帧 → 写入 LatestFrameQueue → 通知推理线程              │
├──────────────────────────────────────────────────────────┤
│  推理线程 (InferenceThread)                               │
│  取最新帧 → Detector 推理 → 写入 DetectionBuffer          │
├──────────────────────────────────────────────────────────┤
│  控制线程 (ControlThread)                                 │
│  取检测结果 → 观测→预测→PID→曲线→量化 → 输出 MouseCommmand │
└──────────────────────────────────────────────────────────┘
```

**同步机制：**
- 采集→推理：`LatestFrameQueue`（SPSC，只保留最新帧 + CV 通知）
- 推理→控制：`DetectionBuffer`（取最新结果）
- 所有线程可被 `shouldExit` 原子变量优雅终止
