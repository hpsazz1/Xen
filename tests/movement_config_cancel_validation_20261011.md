# Movement热配置、取消及ACK交错

纯测试补证，生产movement未改。movement_tests新增四组：configure后cancel、cancel后configure、再关闭当前模式、清理ACK为APPLICATION_UNKNOWN。使用真实Worker线程与内存IMouseController，在方向命令已进入、ACK尚未返回的条件变量屏障内提交热配置和取消，并加入旧动作尾报告。

四组均不得在ACK返回后继续位移；取消只承担本动作清理，旧尾报告不得重启。三个已确认清理组在新epoch实际基线被读取后重新触发，采用新报告模式和两倍角度；未知清理组保持FAULT、共享键盘不归还，stop/start也不能丢掉债务。停止均释放订阅。闸门有三秒兜底并断言没有靠超时放行，不用sleep猜测ACK位置。

初步四组在原生产实现全部通过，因此没有新生产缺陷或性能提升声明。既有movement全专项包含本组，原诊断入口和谓词保留。真实后端ACK/串口/网络重连、设备物理效果与全部状态组合未证明；不连接设备、不启动采集/游戏输入/原生UI/GPU。历史全量中movement首次失败及后续夹具修正仍独立保留，不用本批通过覆盖旧结果。
