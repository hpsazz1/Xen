# X反向缩放候选的有界回放

生产Aim未修改。历史H-SCALE-REV怀疑reverse_takeover_distance的source死区与ROI几何混用；六条实际Aim回放检查同一source轨迹在source/ROI比例0.5、1、2时的公开结果，分直接反向200帧与停后反向240帧。每帧必须同一CONFIRMED实测目标、有效背景帧对已消费、明确零执行回执；固定12source像素死区，其他参数一致。

三缩放的直接反向均在第127帧恢复负前探，停后反向均第157帧；逐帧source前探差小于0.01像素，X命令序列相同。正向末20帧中两帧超过6source像素，停止尾段为零。最初要求全部20帧都超过门槛的断言过强，是夹具失败；原始日志保留，不能作为生产红灯。修正为确有正向激活后，再比较整条公开结果。

这没有复现候选，也没有证明内部每条reverse_takeover分支都被覆盖。尤其停后重入可能走重新激活路径；尚无分支级证据，不按公式外观修改X或Y控制。无完整Runtime/Detector/非零plant新链，无物理效果或体验结论。

坐标映射依据：[OpenCV resize](https://docs.opencv.org/4.13.0/da/d54/group__imgproc__transform.html)，分别按各轴尺寸比例变换几何和位移；只是单轴等价性试验方法，不替代当前代码证据。未复制第三方实现、未变更依赖或许可证。既有AS01宽度、独立延迟plant、形变/纯相机/来源断点和丢失停止回归保持。
